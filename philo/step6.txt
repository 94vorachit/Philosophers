## Next step

Add the monitor thread before the full death logic, with a very small fatal check.

```c
static void	*monitor_routine(void *arg)
{
	t_sim	*sim;
	int		i;

	sim = (t_sim *)arg;
	while (1)
	{
		i = 0;
		while (i < sim->philo_count)
		{
			if (now_ms() - sim->philos[i].last_meal_ms > sim->time_to_die)
			{
				pthread_mutex_lock(&sim->stop_lock);
				sim->stop = true;
				pthread_mutex_unlock(&sim->stop_lock);
				return (NULL);
			}
			i++;
		}
		usleep(1000);
	}
	return (NULL);
}
```

Then create it in `start_simulation` before starting the philosopher threads:

```c
if (pthread_create(&sim->monitor, NULL, monitor_routine, sim) != 0)
	return (0);
```

and join it after the philosopher joins.

### Why this is the correct next step
This is the first real monitor loop:
- it watches each philosopher
- it transitions the simulation to `stop`
- it is the foundation for the actual death detection logic
