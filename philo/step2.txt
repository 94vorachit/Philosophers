## ✅ Step 2 is implemented: simulation initialization

I added the actual setup code for the philosopher/fork state and mutex initialization in init.c, and wired it into main.c. The public API was updated in philo.h.

### What it does
- allocates the fork mutex array
- allocates the philosopher array
- initializes print/state/stop mutexes
- assigns each philosopher:
  - left fork
  - right fork
  - starting meal timestamp
  - pointer back to shared simulation
