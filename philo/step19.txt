## Next step

The next small improvement is to make every philosopher check the stop condition after each action in simulation.c, not only at the start of the loop.

### Why
Right now, the monitor can set the stop flag, but a philosopher may still continue into a later action before it notices. That can cause:
- prints after death
- extra sleep/thinking after the end
- a racey shutdown

### Minimal pattern
Use this structure in the philosopher loop:

```c
while (!is_stopped(philo->sim))
{
	lock_forks(philo);
	eat_action(philo);
	unlock_forks(philo);

	if (is_stopped(philo->sim))
		return (NULL);

	log_action(philo, "is sleeping");
	usleep(philo->sim->time_to_sleep * 1000);

	if (is_stopped(philo->sim))
		return (NULL);

	log_action(philo, "is thinking");
}
```

This is the last small correctness step before final polish and test runs.
