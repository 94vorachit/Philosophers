## Next step

Add the cleanup function that destroys all mutexes and frees memory after the threads finish.

```c
void	cleanup_sim(t_sim *sim)
{
	int	i;

	i = 0;
	while (i < sim->philo_count)
	{
		pthread_mutex_destroy(&sim->forks[i]);
		i++;
	}
	pthread_mutex_destroy(&sim->print_lock);
	pthread_mutex_destroy(&sim->state_lock);
	pthread_mutex_destroy(&sim->stop_lock);
	free(sim->forks);
	free(sim->philos);
}
```

Then call it at the end of `main` after joining everything.

### Why this is the next step
This is the final project lifecycle step:
- threads end
- shared resources are released
- no mutex leaks remain

This is a small, clean finishing step after the simulation logic itself is already working.
